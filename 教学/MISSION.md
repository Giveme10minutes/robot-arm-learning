# MISSION

## 为什么学

2026 年 10 月，参加**四川省大学生机器人大赛 · 人工智能与机器人技术应用挑战赛**（工业无损检测创新赛项）。

赛事现场只有 **90 分钟**，要在其中完成：设备搭建 → 图像采集 → 数据标注 → 模型训练 → 缺陷检测与分类抓取 → 语音播报。因此所有技能必须**提前练到肌肉记忆**，现场不允许学新东西。

## 学习者

- 大二本科生，**有 Python 语法基础**，未学过机器学习
- 手上设备：机械臂（四轴）+ 工业相机 + 传送带 + Jetson Xavier NX 工控机（成都远程巨科整套）
- 时间：赛前数周，需分阶段推进

## 学会之后要能做到

1. 独立在 Windows / Jetson 上搭好 Python 环境并跑通检测程序
2. 用 YOLO11 完成"读相机 → 推理 → 画框"闭环
3. 现场拍图后按固定类别表标注，产出合格数据集
4. 训练自己的模型并复跑推理，且**能报出全流程耗时**
5. 理解手眼标定与像素坐标 → 机械臂坐标的转换
6. 用 Python 控制机械臂完成"抓取 → 放入物料盒"
7. 让电脑播报 `PCB_OK` / `PCB_NG`

## 赛项任务对照（得分点）

| 任务 | 得分 |
|---|---|
| 8 个机加工件识别 + 分类 + 搬运入盒 | 8 分/个，共 64 分 |
| 3 块 PCB 板缺陷检测（1 正常 4 分 + 4 处缺陷 3 分/处） | 共 16 分 |
| 语音播报 PCB 结果 + 震动分类 | 5 分 + 5 分 |
| 职业素养 | 10 分 |
| 重启扣分 / 违规扣分 | −10 分/次 |

## 学习纪律（课程设计原则）

- 每一课都要**跑出可看见的结果**，不是读文档
- 每一课都要**记录耗时**（现场 90 分钟预算是硬约束）
- 标注类别表一旦确定，**顺序和名称不许再改**
- 不追求理解全部原理，**优先"能跑通、能复现、能在现场复现"**
