# NOTES（教学偏好与工作备注）

## 学习者画像
- 大二本科生，Python 语法基础，无机器学习背景
- 目标是"能在赛场上复现"，不是"理解原理"——讲解深度以够用为限
- 多人数、分批学，材料需**可独立阅读**，不依赖当面讲解

## 教学偏好
- 全部中文表述；命令、代码、报错保持原文
- **环境统一约定：所有课程一律用 uv**（`uv init` / `uv add` / `uv run` / `uv sync` / `uv tool install`），不再用 venv + pip；国内镜像用 `UV_DEFAULT_INDEX`；**Python 版本统一 3.11**（全局 `uv python pin --global 3.11` + 项目内 `uv python pin 3.11`，项目级优先于全局）。工控机（Jetson）上的厂商环境不要用 uv 覆盖
- 命令写法以"位置明确"为优先：建项目一律"先 `mkdir` → `cd` 进去 → 再 `uv init`"，不用 `uv init <目录名>` 一步到位（避免学生搞混当前目录）
- 每课**短**，一次一技，结尾有可验证的"跑出什么结果算过关"
- 每课附**真实可访问**的延伸资源（已逐条验证，不用记忆中的链接）
- 强调两件事：**耗时记录**（现场 90 分钟预算）与**类别表纪律**（顺序不许改）
- 用"现场会不会因此丢分"作为每个知识点的取舍标准

## 赛项关键约束（讲课时要反复点到的）
- 90 分钟含搭建：采集 + 标注 + 训练 + 推理全流程
- 每个物品**只允许识别一次**
- 未搬运进物料盒**不得分**
- 分类功能切换**只允许鼠标点屏幕软件**
- 重启扣 10 分（仅一次机会）；违规扣 10 分
- 现场不许联网下载程序、不许带辅助资料、不许联系指导教师 → **agent 只在赛前用**
