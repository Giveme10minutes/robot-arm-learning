术语表

看懂这些词，报错信息和文档就不再是天书。按主题分组，用到哪块查哪块。

一模型与训练

术语一句话解释
数据集（dataset）一堆图片 + 对应的标注文件，模型从里面学东西
标注（labeling）人工在图上把目标框出来并写上类别，产生 txt 标签文件
训练（train）反复看数据集、调整权重参数，让模型的输出越来越准
推理（inference）用训练好的权重去判断新图片里有什么，速度很快
权重（weights，.pt）训练得到的文件，承载"模型学到的知识"；best.pt 即效果最好的那一版
预训练模型别人用海量数据训好的权重，可以直接推理，也可以作为你训练的起点
epoch（轮）把整个数据集完整看一遍叫一轮；epochs=50 就是看 50 遍
batch（批）一次喂给模型的图片数量；太大会爆内存
过拟合模型把训练集"背下来"了，换新图片就失效。数据太少时最容易发生
COCO通用检测数据集，80 个日常类别；预训练模型靠它认识"人、车、瓶子"
n / s / m / l / xYOLO 模型的大小档位，越大越准也越慢。现场优先用最小的 n

二评价指标

术语一句话解释
置信度 conf模型对"这里有个目标"的把握程度，0 到 1
IoU（交并比）预测框与真实框的重叠程度，用来判断"框得准不准"
Precision（精确率）框出来的里面有多少是对的 → 低就是误报多
Recall（召回率）该框的里面有多少被框到了 → 低就是漏检多
mAP50综合评分，主要看它是否随训练上升；比赛更在乎召回率
混淆矩阵一张表，看模型把哪一类错认成了哪一类

三图像处理

术语一句话解释
像素 / 分辨率图像的最小单位；分辨率就是宽 × 高的像素数
通道 / BGR彩色图有 3 个通道。OpenCV 的排列顺序是蓝绿红（BGR），不是常见的 RGB，最容易踩坑
灰度图单通道图像，只有明暗。很多图像处理在灰度上做更快
HSV色调 / 饱和度 / 明度。比 RGB 更适合按"颜色"分离物体
ROI（感兴趣区域）图像里你真正关心的那一小块区域，只处理它能省时间
阈值 / 二值化把灰度图按一个界限变成黑白两色，突出目标
形态学（腐蚀 / 膨胀 / 开 / 闭）给黑白图"去噪点、补空洞"的操作，处理缺陷图像常用
轮廓（contour）二值图里连成一片的目标边界，可用于计算面积、位置
曝光 / 增益工业相机最重要的两个参数：曝光管"进光时间"，增益管"信号放大"
全局快门 / 卷帘快门全局快门整幅同时曝光（拍运动物体不变形），卷帘快门逐行曝光会有形变。赛项指定的是全局快门

四标定与机器人

术语一句话解释
手眼标定求出"相机看到的位置"与"机械臂能到达的位置"之间的换算关系。标定不准 → 认得出但抓不到
像素坐标目标在图像里的位置，以像素为单位（左上角是原点）
机械臂坐标机械臂自己的坐标系（通常以底座为原点），单位是毫米
单应矩阵 H一个 3×3 的矩阵，把平面上的像素坐标直接换算成平面坐标。9 点标定干的就是这件事
归一化坐标YOLO 标签里的坐标写法：像素值除以图片宽高，落在 0 到 1 之间
内参 / 外参内参描述相机自己的成像特性，外参描述相机装在什么位置、朝向哪
末端执行器 / 夹爪机械臂最前端用来干活的部件（夹爪、吸盘、标定笔）
正运动学由各关节角度算出末端到达的位置，SDK 能直接读
回零 / 复位让机械臂回到一个固定初始姿态；每次开机、异常后都要做，通常会有"叮"的一声
工作空间机械臂能达到的范围。赛项要求动作必须在场地范围内
被动分拣 / 震动分类赛项任务之一：把螺丝螺母放到摄像头下，程序判断类型后直接抓取

五平台与部署

术语一句话解释
Jetson Xavier NX赛项要求的工控主控板：带 GPU 的小型嵌入式计算模块，跑 Ubuntu
JetPackNVIDIA 给 Jetson 准备的系统与驱动包（含 CUDA），装 PyTorch 前必须先看它
TensorRTNVIDIA 的推理加速引擎，能把模型跑得更快；Jetson 上常用来提帧率
ONNX一种通用的模型交换格式，多种工具之间倒模型时用
虚拟环境 / .venv给单个项目隔离出来的 Python 环境，避免库版本互相打架
uv课程统一使用的 Python 项目管理工具（Rust 写的，速度快）：建环境、装库、跑脚本一套命令搞定
pyproject.toml项目清单，记录这个项目用了哪些库；配合 uv.lock 就能在别人机器上一键复现同样环境
.python-version记录这个项目用哪个 Python 版本，由 uv python pin 生成；项目里的优先于全局设置
OK / NG合格 / 不合格。赛项要求语音播报 PCB_OK 或 PCB_NG
