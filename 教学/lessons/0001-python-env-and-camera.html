备赛入门 · 学习地图 / 第 1 课

搭好环境，让摄像头画面出现在屏幕上

第 1 课 · 预计 40 至 90 分钟（第一次装环境会慢，记下你的实际用时）

今天的成果 运行一段 Python 程序，屏幕上弹出一个窗口显示摄像头的实时画面，按 q 能退出，并且能按一下键把当前画面存成一张图片。

1先搞懂两件事：虚拟环境与 uv

机器上会同时存在很多个 Python 项目，每个项目需要的库版本不一样。虚拟环境就是给这一个项目准备一个独立的抽屉，装什么都只影响这个抽屉，不会弄乱系统本身。

我们统一用 uv 来管理它。uv 是一个用 Rust 写的 Python 项目管理工具，把"建环境、装库、跑脚本"合成一套命令，速度比传统做法快得多。全班统一用 uv，环境才能对齐，才不会出现"在我电脑上能跑、在你电脑上不行"。

三个概念记住就够了：

东西是什么
pyproject.toml项目的"清单"，记录这个项目用了哪些库
.venv/真正存放库的环境目录，由 uv 自动创建，你不用手动管
uv.lock把每个库锁定到确切版本；别人拿到它和 pyproject.toml，一条命令就能复现一模一样的环境

2动手：装 uv、建项目

步骤
  1. 安装 uv（选你系统对应的那一行）： 
    # Windows（PowerShell）
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh
    装完关掉终端重新开一个，再验证： 
    uv --version
  2. 配置国内镜像（决定后面装库快不快，只需做一次）： 
    # macOS / Linux（写进 ~/.zshrc 或 ~/.bashrc 可永久生效）
export UV_DEFAULT_INDEX="https://pypi.tuna.tsinghua.edu.cn/simple"

# Windows PowerShell（永久生效可加到系统环境变量）
$env:UV_DEFAULT_INDEX="https://pypi.tuna.tsinghua.edu.cn/simple"
  3. 统一 Python 版本（全班都用 3.11）： 
    uv python pin --global 3.11
    这会把 3.11 设为这台机器上 uv 的全局默认 Python 版本（Windows 写在 %APPDATA%\uv\.python-version，macOS / Linux 写在 ~/.config/uv/.python-version）。之后 uv 需要 Python 时会自动下载并使用它，不用你手动装。
    可选、但推荐：先跑一次 uv python install 3.11 把它预装下来——否则第一次用到时才下载，网络不稳或赛场断网时容易卡住。
    选 3.11 的理由：OpenCV、PyTorch、ultralytics 这些库的 3.11 轮子最齐全，装环境最不容易踩坑。
    ⚠ 注意优先级：项目目录里的 .python-version 比全局设置更优先。所以下一步建好项目后，还要进项目里再执行一次 uv python pin 3.11，把版本在项目里也钉死。
  4. 创建项目目录，并进到目录里初始化项目（uv 会顺手准备好 Python 环境）： 
    mkdir robot_training
cd robot_training
uv init
uv python pin 3.11
    说明：uv init 目录名 也能一步建好目录再初始化，两种都合法；但我们统一用"先建目录、进去再执行"的方式，位置最不容易搞混——后面所有命令都要在这个项目目录里执行。
    uv python pin 3.11 会在项目里生成一个 .python-version 文件（内容就是 3.11）。这一层优先于全局设置，也是全班真正对齐的那一层——所以全局、项目各 pin 一次，两边都不会跑偏。
  5. 加入依赖 —— OpenCV 与 NumPy： 
    uv add opencv-python numpy
    这一步会自动建好 .venv，并把依赖写进 pyproject.toml。不需要手动激活环境。
  6. 确认环境可用： 
    uv run python -c "import cv2; print(cv2.__version__)"
    能看到版本号就说明环境好了。
命令的跨平台差异（先分清，少走弯路） mkdir、cd、uv 这几条在 Windows 和 macOS / Linux 上都能直接用——Windows 的命令提示符（CMD）与 PowerShell 都支持 mkdir（CMD 官方说明、PowerShell 别名）。
真正需要按系统区分的只有设置环境变量的写法：
· macOS / Linux：export UV_DEFAULT_INDEX="..."
· Windows PowerShell：$env:UV_DEFAULT_INDEX="..."
另外注意：mkdir -p a/b 这种带 -p 的写法只在 macOS / Linux 有效，CMD 不认；所以课程里统一用最简单的单层 mkdir 目录名。
三条最容易犯的错 ① 装完 uv 马上用，提示"命令找不到"——重开一个终端就好（PATH 需要重新加载）。
② 混用 pip install 和 uv add——pip 会装到别的地方（甚至系统 Python），之后 uv run 时报"找不到 cv2"。课程里统一用 uv add。
③ 在项目目录之外运行 uv run——它找不到 pyproject.toml。执行命令前先 cd 回项目目录。

3动手：让画面出来

在项目目录里新建文件 camera.py，内容如下：

import cv2

cap = cv2.VideoCapture(0)          # 0 表示默认摄像头；打不开就试 1
if not cap.isOpened():
    raise SystemExit("打不开摄像头：换索引试试，或检查系统权限")

cap.set(cv2.CAP_PROP_FRAME_WIDTH, 1280)
cap.set(cv2.CAP_PROP_FRAME_HEIGHT, 720)

while True:
    ok, frame = cap.read()
    if not ok:
        print("读帧失败")
        break

    print(frame.shape, frame.dtype)   # 看一眼"图像"在程序里长什么样

    cv2.imshow("camera", frame)
    key = cv2.waitKey(1) & 0xFF
    if key == ord("q"):                # 按 q 退出
        break
    if key == ord("s"):                # 按 s 存一张图
        cv2.imwrite("shot.jpg", frame)
        print("已保存 shot.jpg")

cap.release()
cv2.destroyAllWindows()

用 uv 运行它（注意是 uv run，不要直接 python）：

uv run python camera.py
过关标准 ① 弹出窗口能看到自己（shot.jpg 能存下来）；② 窗口关闭后程序正常退出，不留黑窗口；③ 你已经知道自己跑通这一步花了多少分钟。
顺手做一件事：在循环里打印 frame.shape，看看那个三维数字，并在 术语表里找到"BGR"这个词记下来。

4几个必踩的坑（先看，能省半小时）

现象原因与处理
uv 命令找不到装完没重开终端；或安装路径没进 PATH，重开终端后再试
import cv2 报"找不到模块"用了 python camera.py 而不是 uv run python camera.py，或当初是用 pip 装的库
窗口一片黑 / 打不开摄像头索引不对，把 VideoCapture(0) 改成 1 或 2 试
macOS 上直接报权限错误系统设置 → 隐私与安全性 → 摄像头，允许终端 / 你的编辑器访问
窗口卡死、点不动必须有 cv2.waitKey(1)，它负责处理窗口事件
画面颜色发蓝或红蓝反了OpenCV 用 BGR，其他库常用 RGB；转换用 cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
装库特别慢或失败镜像没配好，回去做第 2 步的 UV_DEFAULT_INDEX
