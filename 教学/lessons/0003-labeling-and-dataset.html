备赛入门 · 学习地图 / 第 3 课

拍图、标注，做出自己的数据集

第 3 课 · 预计 1.5 至 2.5 小时（标注是最费时间的环节，别指望十几分钟干完）

今天的成果 手里有一份符合 YOLO 格式的数据集：至少 2 个类别、每类 20 张以上的图片和对应的标签文件，并且有一个 data.yaml 能把它描述清楚，让训练程序一读就懂。

1先搞清楚 YOLO 的数据长什么样

训练不是"把图片丢进去"就行了。YOLO 要的是每张图片配一个同名 txt 文件，里面每一行描述一个目标：

# 文件名：img_001.jpg  →  标签文件：img_001.txt
# 每行格式：类别序号  中心点x  中心点y  宽  高
# 后 4 个数字都是 0 到 1 之间的小数（除以图片宽高得到的比例）
0 0.512 0.487 0.201 0.223
1 0.155 0.902 0.089 0.114
三个必须记住的规则 ① 文件名必须一一对应：有图片没标签（或反之）会被程序忽略或报错。
② 坐标是归一化的比例，不是像素——所以换分辨率不用重标。
③ 类别从 0 开始编号，与 classes.txt 的行顺序严格对应。顺序定了不许改。

2动手一：采集图片

用第 1 课的脚本改一个采集版本：按空格存一张、按 q 退出，自动按序号命名。存成 collect.py，用 uv run python collect.py 运行。

import cv2, os, time

os.makedirs("images_raw", exist_ok=True)
cap = cv2.VideoCapture(0)
n = 0

while True:
    ok, frame = cap.read()
    if not ok:
        break
    cv2.imshow("collect", frame)
    key = cv2.waitKey(1) & 0xFF
    if key == ord(" "):
        n += 1
        path = f"images_raw/{int(time.time()*1000)}_{n:03d}.jpg"
        cv2.imwrite(path, frame)
        print("saved", path)
    elif key == ord("q"):
        break

cap.release()
cv2.destroyAllWindows()
采集要求（直接影响模型效果） 每类至少 20 张，而且要换角度、换位置、换光照、换背景拍。全都从同一个角度拍 20 张，等于只给了 1 张。赛场上的物料位置是随机的，训练数据越"花"，模型越稳。

3动手二：标注

用 labelImg 标注（厂商手册也是这个工具）
  1. 安装并启动（标注工具属于"命令行工具"，用 uv 单独装）： 
    uv tool install labelImg
labelImg
  2. 左下角把格式切换为 YOLO（不是 PascalVOC）。
  3. 点"打开目录"选中 images_raw，先确定类别：类别顺序一旦定下，之后所有课都不许改。
  4. 按 w 画框 → 输入类别名 → Ctrl+S 保存 → 按 d 下一张。
    标注时把物体框紧一些，不要框一大圈留白。
  5. 标完后检查：images_raw 里每张 .jpg 都应该有一个同名 .txt。
小目标上的注意点 赛项里 PCB 板上的缺陷可能只有几十个像素，标注时放大图片再画框（labelImg 支持缩放），框紧、不重叠、不漏标。这一课先用零件练手，养成"放大再标"的习惯。

4动手三：整理成数据集目录

dataset/
├── images/
│   ├── train/          # 约 80% 的图片
│   └── val/            # 约 20% 的图片（留着检验效果，不参与训练）
├── labels/
│   ├── train/          # 与 train 图片同名的 txt
│   └── val/
└── data.yaml

data.yaml 内容：

path: ./dataset
train: images/train
val: images/val

names:
  0: nut          # 类别顺序必须与你标注时用的顺序一致
  1: screw
过关标准 ① 每类 20 张以上、图片与标签一一对应；② data.yaml 的 names 顺序与标注一致；③ 你能说出"训练集和验证集为什么要分开"；④ 记录标注总耗时（这个数字在赛场上非常关键）。

5常见坑

现象原因与处理
标了半天，退出后全没了忘记保存。labelImg 每张都要 Ctrl+S，养成"画框后就按一下"的习惯
训练时报"类别数不匹配"data.yaml 的 names 数量或顺序与标签里的序号不一致
图片和标签错位某张图没有对应 txt（或反过来），文件名对不上
模型把两类混为一类类别之间长得像、标注又不一致（同一种零件有时标 A 有时标 B），标准必须统一
Windows 上 labelImg 启动报错labelImg 项目已归档，可改用 X-AnyLabeling 或在线平台 Roboflow，标注结果同样能导出 YOLO 格式
