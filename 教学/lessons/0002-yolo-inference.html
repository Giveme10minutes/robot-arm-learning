备赛入门 · 学习地图 / 第 2 课

让程序认出画面里的东西

第 2 课 · 预计 40 至 70 分钟（含首次下载模型的时间）

今天的成果 摄像头画面里出现的东西被框出来，框上标着它的名字和置信度；你能在终端里打印出"检测到了什么、在哪里、有多确定"。同时你会亲自体会到一件事：它认不出我们真正要认的东西。

1先建立三个概念

概念一句话理解
目标检测不仅要知道画面里"有什么"，还要知道"在哪"——输出一串框，每个框带类别和置信度
YOLO一类检测算法的名字，特点是"看一眼就出结果"（一次前向计算给出所有框），所以能做实时视频
预训练模型别人已经用海量数据训练好的权重文件。你直接拿来用 = 推理；拿自己的数据继续训练 = 训练。本课只做推理

2动手：跑通推理

步骤
  1. 环境里装上 ultralytics（YOLO 的官方库）： 
    uv add ultralytics
  2. 新建 detect.py，运行后第一次会自动下载权重文件 yolo11n.pt（约 5 MB）： 
    import cv2
from ultralytics import YOLO

model = YOLO("yolo11n.pt")        # n = nano，最小最快的一档
cap = cv2.VideoCapture(0)

while True:
    ok, frame = cap.read()
    if not ok:
        break

    results = model(frame, conf=0.4, verbose=False)
    r = results[0]

    for box in r.boxes:            # 每个框：类别、置信度、坐标
        cls_id = int(box.cls[0])
        conf = float(box.conf[0])
        x1, y1, x2, y2 = box.xyxy[0].tolist()
        print(f"{model.names[cls_id]}  conf={conf:.2f}  box=({x1:.0f},{y1:.0f},{x2:.0f},{y2:.0f})")

    cv2.imshow("yolo", r.plot())    # plot() 直接返回画好框的图
    if cv2.waitKey(1) & 0xFF == ord("q"):
        break

cap.release()
cv2.destroyAllWindows()
  3. 运行 uv run python detect.py，把手机、水杯、人放进画面试试。
过关标准 ① 画面里的常见物体被框住并显示英文类别名；② 你能说清 boxes 里每个框包含哪三类信息；③ 记录两个数字：帧率大概多少（画面流不流畅）、整节课花了多少分钟。

3关键一步：亲手验证"它不会用"

拿一颗螺母或螺丝放到摄像头前，看看会发生什么。多半是：什么都检测不到，或者被误认成别的东西。

这就是本课最重要的收获 预训练模型是在 COCO 数据集上训练的，只有 80 个类别（人、车、瓶子、椅子等日常物体），里面没有"螺母"，更没有"PCB 板上的焊点缺陷"。而且赛项要检测的是小目标（小小的零件、板子上几毫米的缺陷），比人这种大目标难得多。

所以：赛场上必须用自己拍、自己标、自己训的模型——这正是第 3、4 课要做的事。

4常见坑

现象原因与处理
首次运行卡住很久在下载权重文件；网络慢可以手动下载 yolo11n.pt 放到脚本同目录
画面很卡CPU 推理较慢，属正常。可把分辨率降到 640×480、或每 2 帧检测一次（跳帧）
框太多太杂调高 conf（例如 0.5 至 0.6）只保留高置信度的框
想只看某一类加参数 classes=[0] 只检测人；或在循环里按名字过滤
同一物体每帧框位置抖动正常现象，检测是逐帧独立的；需要稳定结果可做多帧投票
