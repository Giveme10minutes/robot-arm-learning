备赛入门 · 学习地图 / 第 4 课

训练自己的模型，再用它识别一次

第 4 课 · 预计 1 至 2 小时（训练本身可能要跑十几分钟到几十分钟，趁这段时间做别的事）

今天的成果 用第 3 课的数据训练出一个模型，把第 2 课的程序里的 yolo11n.pt 换成你自己训出来的 best.pt，摄像头前的零件被正确认出并框住。同时你手里有一张"训练耗时记录表"。

1训练命令

# 用命令行训练（最简单；ultralytics 已装进项目环境，所以走 uv run）
uv run yolo train model=yolo11n.pt data=dataset/data.yaml epochs=50 imgsz=640 batch=8

# 或者写成 train.py 再运行
uv run python train.py
参数含义怎么定
model训练起点先用 yolo11n.pt：小、快，适合现场
epochs把数据集完整过多少遍数据少时 50 至 100；先用 20 轮试通再加大
imgsz训练时图片缩放到的边长640 是默认；小目标可以试 960 或 1280
batch一次喂多少张显存/内存不够就减小（4、2）

2训练时该看什么

  • 终端会滚动打印每一轮的结果：损失值（box_loss、cls_loss）应该整体下降。
  • 结果全部存在 runs/detect/train/ 目录（第二次训练会变成 train2、train3……）：
runs/detect/train/
├── weights/
│   ├── best.pt      # 效果最好的那一版权重 ← 你要用的就是它
│   └── last.pt      # 最后一轮的权重，一般不用
├── results.csv      # 每轮的指标，可以用 Excel 打开看曲线
├── confusion_matrix.png
└── val_batch0_pred.jpg   # 验证集的预测效果图，最直观

三个指标，够用了

指标看什么
Precision（精确率）框出来的东西里，有多少是真的。低 = 误报多
Recall（召回率）真的目标里，有多少被框出来了。低 = 漏检多
mAP50综合分，越高越好。重点看这个数字是否随训练上升
赛场上要的是 Recall（不漏检） 漏了一个零件 = 少得 8 分；偶尔误报一次，代价小得多。所以训练后如果发现召回率低，优先加数据、加轮次、提高 imgsz，而不是去调高置信度阈值。

3用自己的模型复跑第 2 课

把第 2 课 detect.py 里的一行改掉就行：

# model = YOLO("yolo11n.pt")
model = YOLO("runs/detect/train/weights/best.pt")   # 换成自己训的

然后照样用 uv 运行：

uv run python detect.py
过关标准 ① 摄像头前的零件被正确识别，类别名与你的 data.yaml 一致；② 你能指出 best.pt 在哪、train 和 train2 的区别；③ 填完下面这张表——这是本课最重要的产出。

4训练耗时记录表（必须填）

现场只有 90 分钟，你必须知道自己"训练一轮要多久"。至少跑两组对比，把数字记下来：

设备类别数 / 每类张数模型epochsimgsz耗时mAP50
笔记本（CPU）2 / 20yolo11n20640  
笔记本（GPU）2 / 20yolo11n50640  
Jetson Xavier NX2 / 20yolo11n20640  
为什么要填这张表 厂商手册建议"训练 100 轮以上"，那是在有独立显卡的电脑上的经验。在 Jetson Xavier NX 上现场训练会慢得多，很可能 90 分钟内跑不到 100 轮。这张表就是你的决策依据：现场到底用多少轮、多少张图、多大分辨率，全看这里的数字。

5常见坑

现象原因与处理
报"内存不足 / out of memory"减小 batch、减小 imgsz
训练很快结束但效果很差数据太少或标注不一致；先检查 val_batch0_pred.jpg 里框得对不对
mAP 一直是 0 或很低类别顺序错位、标签文件对不上图片、图片路径写错——回到第 3 课的检查清单
找不到 best.pt结果目录按次数递增（train2、train3），去最新的那个目录里找
换到 Jetson 跑不起来PyTorch 必须用 Jetson 专用版本，见官方 Jetson 部署指南
